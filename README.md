A cross-platform (macOS / Windows / Linux) tray daemon that tells you **which Claude Code session just finished** when you're running several at once.

No more walking through every terminal to check:

- ✅ Native OS notification on task completion (Stop) / 🔔 when input is needed (Notification)
- Notification title = **session title** (including titles generated by the VSCode extension), subtitle = **project path**, body = **one-line AI summary** (`claude -p --model haiku`, using your existing auth · falls back to an excerpt of the last reply)
- On macOS with `terminal-notifier` installed, **clicking a notification focuses that session's IDE** (VSCode / Cursor / Windsurf auto-detected)
- Tray menu with recent events — click one to open the project folder
- Completed-task count badge in the macOS menu bar

## How it works

```
Claude Code ──(Stop / Notification hook)──▶ claude-notify hook
                                                │  POST localhost:49517
                                                ▼
                                          tray daemon ──▶ OS notification + event list
```

If the daemon isn't running, the hook falls back to sending the OS notification directly, so notifications keep working even with only the hook installed.

## Install

One line — downloads the binary, registers the Claude Code hooks, and sets up login autostart:

```sh
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/CoderGangW/claude-notify/main/install.sh | sh
```

```powershell
# Windows
irm https://raw.githubusercontent.com/CoderGangW/claude-notify/main/install.ps1 | iex
```

With Go installed:

```sh
go install github.com/CoderGangW/claude-notify@latest
claude-notify install   # register hooks + autostart + start the daemon
```

From source:

```sh
git clone https://github.com/CoderGangW/claude-notify
cd claude-notify
go build -o claude-notify .
```

## Commands

| Command | Description |
|---|---|
| `claude-notify` | Run the tray daemon (default) |
| `claude-notify install` | Register Stop/Notification hooks + login autostart (LaunchAgent / XDG autostart / registry) + start the daemon |
| `claude-notify uninstall` | Remove the hooks and the autostart registration |
| `claude-notify hook` | Hook endpoint called by Claude Code (never run manually) |
| `claude-notify peek <transcript.jsonl> [session-id]` | Debug: print the title/summary sources resolved for a session |

## Custom icon

Tray icons are embedded at build time. Replace `assets/icon.png` (Windows/Linux, color) and `assets/icon_mac.png` (macOS menu bar, monochrome template) with any 32×32 PNG and run `go build`.

## Platform notes

- **macOS**: `brew install terminal-notifier` strongly recommended — click-to-focus-IDE and the path subtitle. Allow terminal-notifier in System Settings → Notifications on first use. Without it, falls back to `osascript` (notifications show as "Script Editor", no click action). The notification sender shows as terminal-notifier (a native sender name needs an .app bundle — on the roadmap).
- **AI summary**: used automatically when the `claude` CLI is on PATH (the notification arrives a few seconds later while the summary is generated). Disable with `CLAUDE_NOTIFY_NO_AI=1`. Hook recursion from the summarizer's own session is blocked by the `CLAUDE_NOTIFY_SUPPRESS` guard.
- **Linux**: needs `libayatana-appindicator` for the tray and `notify-send` (libnotify) for notifications.
- **Windows**: toast notifications, no extra dependencies.
