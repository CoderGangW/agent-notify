- **Native-feeling tray popovers (macOS)**: the dashboard and the right-click menu now open as popovers with a small dome pointing at the tray icon, and fade + scale in and out instead of popping.
- **Tray icon toggles**: clicking the tray icon again closes the dashboard (right-click does the same for the menu) — no more Esc or clicking elsewhere.
- Fixed (Retina): expanding the window could shove it down the screen — the screen bounds were read in pixels instead of points.
- The version picker shows a spinner while it loads the release list.
