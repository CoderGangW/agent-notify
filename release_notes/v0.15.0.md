- Session window: rename a session (inspector button, right-click, or Enter / F2). The name is saved where the agent keeps it, so its own resume list shows it too. Supported for Claude Code, Codex, Gemini, Antigravity and opencode; running sessions can't be renamed.
- Session window: the inspector shows the last 3 turns of the conversation. Long messages fold and open with a click.
- Session window: the inspector shows more about the selected session: the project as a chip that opens the folder, quick stats (last active, duration, size and file count), and the model and git branch.

<details><summary>🇨🇳 简体中文</summary>

- 会话窗口：可以重命名会话（检查器按钮、右键菜单或 Enter / F2）。名称写入代理自己保存的位置，因此代理自身的恢复列表也会显示。支持 Claude Code、Codex、Gemini、Antigravity 和 opencode；运行中的会话不能重命名。
- 会话窗口：检查器显示最近 3 轮对话。长消息默认折叠，点击展开。
- 会话窗口：所选会话显示更多信息：项目以标签显示（点击打开文件夹），概览最后活动、持续时间、大小与文件数，以及模型和 git 分支。
