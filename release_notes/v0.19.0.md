- Session window: read a session's whole conversation. Open it from "View all" in the inspector, the right-click menu, or Space (Esc closes). The inspector itself now shows just the latest exchange.
- Session window: round checkboxes on every row, plus a select-all check in the header. A check adds or removes that row without clearing the rest; Shift selects a range.
- Session window: the Project column shows a folder-name chip instead of the full path (the path is in the tooltip).
- Session window: click the location path in the inspector to open that folder in Finder, Explorer or your Linux file manager, or tells you when it no longer exists.
- Session window: right-click a project in the sidebar to delete all of its sessions. Running and protected sessions are skipped, and the project's own files are never touched.
