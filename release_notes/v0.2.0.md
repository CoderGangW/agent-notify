## agent-notify 0.2.0

- Wails v3 dashboard window: live sessions (state, current tool, ticking turn timer), token usage (local transcript aggregation, per-model), plan limit gauges with the subscription plan
- Claude / Codex tabs with per-source unread badges, mark-all-read, pinnable default tab
- Codex CLI support via its notify hook (`agent-notify install-codex`)
- i18n: English / 한국어 / 简体中文 (single-source `i18n/*.json`), AI summary follows the app language
- New icon set: Lucide bell + \`>-\` prompt glyph on a purple gradient squircle
- Signed universal macOS .app (double-click installs hooks on first run), Windows exe with icon and no console window, Linux app-menu entry
- Tokenless auto-update from GitHub releases (opt out: `disableAutoUpdate`)
- Renamed from claude-notify; fixed bundle id and config dir are kept
